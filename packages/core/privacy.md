# Приватность Искры
- Local-first; уровни: local → private → shared → world-aggregate.
- Opt-in/отзыв в любой момент; GDPR/CCPA принципы; никаких личных текстов в агрегатах.
- Журнал действий хранится локально; экспорт по запросу.
- Шифрование: AES-256 для shadow/memory; ключи генерирует пользователь.
- Bias mitigation в поиске; никакого трекинга без согласия.
