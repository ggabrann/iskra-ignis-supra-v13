# Безопасность (Искра v13.1)
Хранение: AES-256 (shadow/memory). Согласие: double opt-in; отзыв мгновенно.
JWT для клиентов/API; 2FA рекомендована (см. clients).
Чек-лист: шифрование, нет PII в логах, 2FA на критичных точках, регулярные зашифрованные бэкапы.
Запрет на внешние «консенсус/резонанс» механизмы — как источник дрейфа.
